# Mario Roguelike Console Game

Assignment repo for Semester 1 - 2022, FIT2099 - object oriented design and implementation  

This assignment was completed during FIT2099, object oriented design and implementation course during university. The objective was to incorporate new functionalities into the game skeleton across multiple assignments. The project required us to apply our knowledge of object-oriented programming, UML, and sequence diagrams that we had acquired during the semester.  

### Locations:
- To view the UML, design rationale, and sequence diagram for each assignment, please view FIT2099 Assignment X.pdf located under docs.
- The game engine (game skeleton) is located under src/edu/monash/fit2099/engine
- The implementation is located under src/game
